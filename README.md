# TITAN — 鋼索機動狩獵

第一人稱鋼索機動狩獵遊戲。純前端單人，Three.js 手刻，不載任何外部模型或音檔，
所有巨大生物與城市都是程式生成的幾何體。原創題材與命名，與任何其他作品無關。

## 執行

```bash
npm install
npm run dev      # http://localhost:5174
```

`npm run build` 會輸出到 `dist/`，是完全靜態的檔案，丟到任何靜態主機都能跑。

| 按鍵 | 動作 |
| --- | --- |
| 滑鼠左鍵 | 發射左鉤索（按住維持，放開脫鉤） |

## 核心規則

**傷害 = 揮刀當下的移動速度。** 站著砍只會彈開刀刃，得先用鉤索把速度拉起來。

```
傷害 = 12 + 速度(m/s) × 3.4      速度低於 8.4 m/s（約 30 km/h）完全無效
```

身高分三個級距，都拿房子當量尺（一般街廓房子基礎高度約 18m）：

| 泰坦 | 身高 | 換算 | 後頸耐久 | 一擊必殺所需速度 |
| --- | --- | --- | --- | --- |
| 小型 | 9 m | 半個房子高 | 55 | 約 46 km/h |
| 一般 | 18 m | 跟房子差不多高 | 100 | 約 93 km/h |
| 異常型 | 18 m | 跟房子差不多高 | 120 | 約 114 km/h |
| 大型 | 25 m | 比房子高一截 | 165 | 約 162 km/h |

其他規則：

- **只有後頸算弱點**（泰坦身上那塊紅色方塊）。泰坦轉身有轉速上限，繞到背後是可行的戰術。
- **準心會提示時機**：弱點進入攻擊範圍時準心張開，綠色 = 速度夠，紅色 = 太慢會被彈開。
- **砍手臂會打出硬直**：削不到弱點時先廢一隻手，換來 1.8 秒的空檔。砍肉體很傷刀（耐久 −38）。
- **鉤索可以掛在泰坦身上**。錨點會跟著泰坦移動，這是繞背最快的方法。
- **瓦斯只有落地或清空一波才會補**。捲揚機本身也吃瓦斯。
- **落地衝擊**只在垂直速度超過 46 m/s（約 166 km/h）時才計算，單次上限 38 點，
  落地瞬間按著煞車再減免 40%。正常盪來盪去、掃過屋頂都不會扣血。
- 被泰坦打中會被甩飛而且鉤索全斷。
- **體力會緩慢回復**，但要脫離戰鬥才行：離最近的活泰坦超過 40 m、
  且最後一次受傷過了 5 秒才會啟動，之後每秒回 4.5 點（血條會變綠色）。
  站在原地硬撐不會回血，得先撤退拉開距離。波次間的補給空檔是主要的回血窗口。

## 變身泰坦（限時終極技）

揮刀命中泰坦會累積左下角的變身量表（命中弱點 +14、命中肉體 +5、擊殺再 +20），
滿了按 **T** 就能變身，效果：

- 持續 16 秒，**完全免疫傷害**，時間到自動變回人類
- 不能用鋼索／瓦斯／刀刃，改成純地面步行（比人類慢很多，但比一般泰坦快）
- 滑鼠左鍵改成揮拳：固定 260 傷害直接打在對方後頸耐久上，**任何角度都算數**——
  不像刀刃一定要繞到背後，這是「泰坦對泰坦正面對幹」跟「鋼索繞背偷襲」刻意做出的手感差異
- 變身中不會再累積量表，逼你想清楚什麼時候用

## 頭目泰坦

每 5 波（第 5、10、15…波）會額外出現一隻頭目泰坦，體型明顯比「大型」還大、
後頸耐久要好幾刀才砍得完，畫面上方會出現牠專屬的血條。九隻各自只有一招，
輪完一輪會重複出場並提升強度：

| 頭目 | 招式 |
| --- | --- |
| 疾影泰坦 | 速度極快、攻擊冷卻短，純粹靠速度纏鬥 |
| 遊獵泰坦 | 玩家靠太近就轉身逃跑，得用鉤索才追得上 |
| 重甲泰坦 | 蓄力後直線衝鋒，衝完有硬直，是輸出視窗 |
| 投石泰坦 | 對玩家當下位置丟石頭，範圍傷害 |
| 灼焰泰坦 | 地面警示圈膨脹後，以自身為中心炸出蒸氣範圍傷害 |
| 硬殼泰坦 | 週期性硬化，硬化中傷害減免 85% |
| 尖刺泰坦 | 標記玩家腳下，延遲後地面竄出尖刺 |
| 狂暴泰坦 | 弱點耐久掉到一半以下就永久暴走，變得更快更痛 |
| 號令泰坦 | 週期性自我回復並短暫加速，是九隻裡最強的一隻 |

## 鉤索的物理模型

寫在 `hookGear.js` 開頭，三條規則疊起來就是「盪」：

1. 掛上去之後繩長**只會變短**（捲揚機收繩），不會變長 —— 是繩子不是橡皮筋
2. 沿繩索方向持續施加**拉力**（`HOOK_PULL_ACCEL`，明顯大於重力，所以光靠鉤索就能爬升）
3. 實際距離超過繩長時，用**彈簧回拉 + 削掉離心速度**，直線運動就被彎成圓弧

第 3 點刻意用彈簧而不是剛體約束：剛體在高速下會把人瞬間拉停，彈簧才畫得出圓弧。

瞄準方向就是準心正中央，**沒有**額外的偏移角度。曾經讓左右鉤各往外偏 6.5 度，
純粹為了讓兩條繩子視覺上張開，但泰坦的身體遠比建築物窄，距離一拉開，
這個偏移換算成的側向誤差就足以讓鉤爪直接飛過泰坦兩側完全打空——這是「鉤索射不到
泰坦身上」的根本原因，不是泰坦太小或距離太遠的問題。

## 調校建議

物理參數是憑手感估的，實際玩起來要改就改 `constants.js`：

- **飛不太起來** → 調高 `HOOK_PULL_ACCEL` 或 `GAS_THRUST`
- **飛太快、降落不了** → 調高 `BRAKE_DRAG`，或調低 `HOOK_PULL_FALLOFF`（拉力歸零的速度）
- **盪起來太飄、停不下來** → 調高 `AIR_DRAG`
- **站不住屋頂、會滑出去** → 調高 `LANDING_FRICTION`
- **還是常常摔到扣血** → 調高 `FALL_DAMAGE_SPEED`（門檻）或調低 `FALL_DAMAGE_MAX`（上限）；
  兩者都設成很極端的值就等於關掉落地傷害
- **回血太慢／太快** → 調 `HP_REGEN_RATE`；**太難脫離戰鬥觸發回血** → 調高 `HP_REGEN_SAFE_DISTANCE`
  或調低 `HP_REGEN_DELAY`
- **繩子太軟、轉彎不夠俐落** → 調高 `ROPE_SPRING` 與 `ROPE_DAMP`
- **砍不中弱點** → 調高 `BLADE_REACH`
- **鉤索射不到泰坦** → 檢查 `hookGear.js` 的 `fire()` 有沒有又加了瞄準偏移角度；這裡必須跟準心完全一致
- **泰坦看起來還是太小** → 調高 `TITAN_TYPES` 裡的 `height`（注意城牆是 52m、最高建築約 48m，
  身高別超過天際線，不然反而看不出「大」）
- **太難** → 調低 `MIN_KILL_SPEED`、`WAVE_GROWTH`，或調高 `BLADE_SPEED_DAMAGE`
- **變身量表存太慢／太快** → 調 `TITAN_FORM_GAUGE_PER_NAPE_HIT` / `_BODY_HIT` / `_KILL`
- **變身時間太短／太長** → 調 `TITAN_FORM_DURATION`
- **頭目泰坦出現得太頻繁／太少** → 調 `BOSS_WAVE_INTERVAL`；**重複輪次太簡單** → 調高 `BOSS_REPEAT_SCALE`
